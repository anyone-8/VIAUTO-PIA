# VIAUTO-PIA
Proyecto PIA

# **Estructura del proyecto**
la estructura será a como esta en el github. se recomienda crear una carpeta en el escritorio donde guardar la informacion. Ademas, si VS code no ejecuta el archivo simplemente cambien su ruta. esto se hace en el cmd pequeño que abre VS code, poniendo cd.. hasta el nombre de usuario del equipo y posteriormente poniendo cd Desktop/nombre de la carpeta

Para la carpeta se recomienda el nombre de pia

## __Frontend__
deberán tener las siguientes competencias.
- saber usar funciones
- saber leer diccionarios (json)
- saber importar funciones

para este proyecto se usara la customtkinter. por lo que se pide su aprendizaje

## __Backend__
deberan poseer las siguientes competencias
- Saber leer diccionarios (json/bases de datos)
- saber crear funciones bajo suposiciones
- saber crear codigo independiente al tipo de entrada
- entender el uso de ciclos While

### __ayuda__
Tratare de brindar la mayor ayuda posible, pero se recomienda que cada quien avance en lo suyo junto a su pareja. Si requieren saber algo de backend o necesitan que el benackd haga algo en especifico la comunicacion sera importante, igualmente del otro lado. Se recomienda no cambiar, borrar o eliminar partes del github que no sean de su competencia y sin previo aviso

### __Uso de IA__
No se admite el uso de IA generativa para suplir las tareas de su rol. Se acepta el uso para aclaraciones o consultas privadas. En caso que se sospeche de su uso el integrante deberá explicar su código en un README junto con todo lo que se supone que realiza el codigo paso a paso.
