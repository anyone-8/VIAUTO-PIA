# __Instrucciones__

- En base a las funciones programadas en la carpeta backend se deberá realizar un archivo que cree una ventana para elegir una de las funciones ya programadas.

- Para esto se deben importar las funciones del backend para su utilización por lo que se recomienda echarles un ojo o probarlas para saber que devuelve o bien preguntar al banckend.

- Se debera usar una carpeta llamada de manera temporal frontend para la modulacion del archivo principal.

- Todos los commits deben estar comentados dependiendo su complejidad. Para correcciones mínimas se puede omitir este paso
